Frequently asked questions

Is ChalkBored actually free?

Yes. No account fees, no premium tier, no ads. If that ever changes, this page will say so.

Do I need to make an account?

Nope, only password of sorts that will need to be entered is your teachers room code.

How often will the site be updated?

Since release I have been updating the site everyday! You can check for recent changes on the github page.

Is it open source?

Yes! All code is avaliable to anyone on Github.

Is my information private?

Yup, no information is taken let alone shared.
