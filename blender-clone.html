Camera▾
Camera Mode: View scene from selected camera perspective.
Add Camera: Creates a new camera object in the scene.
Viewport: Shows camera preview in corner.
Align View: Moves view to match selected camera.
Camera to View: Moves selected camera to current view.
Numpad 0: Toggle camera mode for selected camera.
Edit Tools▾
Ctrl+C / Ctrl+V: Copy/Paste
Ctrl+D: Duplicate
Delete / Backspace: Delete selected
Ctrl+A: Select All
Esc: Deselect
Numpad 0: Toggle camera mode
Ctrl+Numpad 0: Switch to camera view
Render Settings▾
Render Image: High-quality screenshot with current settings.
Quick Preview: Low-res preview for composition checks.
AA Samples: Anti-aliasing quality (higher = smoother edges).
Renders in real-time using Eevee-style rasterization engine.
Graphics & Performance▾
SSAO: Ambient occlusion for better depth (performance impact: low).
FXAA: Fast anti-aliasing (performance impact: very low).
Shadow Quality: Higher = smoother shadows, lower = better performance.
Shadow Bias: Fixes gaps between objects and shadows (negative values).
Normal Bias: Reduces shadow acne on angled surfaces.
Optimize: Reduces geometry complexity for better performance.
Transform▾
G = Move   R = Rotate   S = Scale
Hold Shift to disable snapping while transforming.
Shift + A to open Add Menu.
Lighting▾
Fake bloom effect using textured sprites at light sources.
More visible when looking toward lights. Reload if lights disappear.

Materials▾
Select a mesh to modify its material.
Upload an image for texture or adjust color, roughness, and metalness.

Scene / Bones▾

Skeletons (bones) will show helper lines + small handles for selection.
